Glosario técnico

  • Acumulador: es una variable que sirve para acumular variables.
  • Algoritmo: es un conjunto de pasos ordenados para resolver un problema.
  • Archivo: es un conjunto de información que puede ser una imagen, texto, un video, etc.
  • Archivo .bat: es un conjunto de comandos de CMD que se ejecutan automáticamente al abrir el .bat.
  • Bloque: es una figura que realiza una acción.
  • Bucle: es una instrucción que se repite varias veces.
  • Carpeta: es un lugar donde se puede almacenar archivos o más carpetas.
  • Clon: crea una copia local de un repositorio remoto.
  • CMD: es la ventana de comando de Windows; con ella se pueden ejecutar o crear cosas mediante comandos.
  • Comando: es una instrucción de texto que le dice a la computadora qué hacer.
  • Commit: es un registro o guardado de los cambios realizados en un proyecto, acompañado de un mensaje que describe qué se modificó.
  • Condicional: es una instrucción que se cumple dependiendo de si la acción es verdadera o falsa.
  • Contador: es una variable que sirve para contar otros datos necesarios.
  • Constante: espacio de memoria donde se almacena un dato que no cambia.
  • Copy: es un comando que permite copiar documentos de un lugar a otro.
  • CSS: lenguaje que define el diseño y la apariencia de una página web.
  • Echo: comando que muestra un mensaje en pantalla.
  • Extensión: es la parte final del nombre de un archivo que indica qué tipo de archivo es.
  • Fetch: Descarga los cambios del repositorio remoto, pero sin aplicarlos automáticamente.
  • Fork: es una copia completa de un proyecto que se crea en tu propia cuenta para que puedas modificarlo sin afectar el proyecto original.
  • Git: es un sistema de control de versiones que permite llevar un registro de los cambios realizados en un proyecto.
  • GitHub: es una plataforma que te permite guardar, compartir, y trabajar en proyectos de programación o diseño web de forma colaborativa.
  • Google Drive: es un servicio en la nube que nos permite guardar archivos y compartirlos con otras personas.
  • HTML: lenguaje que estructura el contenido de una página web.
  • IDE: programa que reúne herramientas para ejecutar, escribir y editar el código en un solo lugar.
  • Javascript: lenguaje de programación que añade interactividad y dinamismo a la página web.
  • Merge (fusión): es el proceso de unir los cambios de una branch (rama) con otra.
  • Mkdir: es un comando de CMD que crea una carpeta.
  • PSeInt: es un programa que permite escribir y practicar algoritmos mediante pseudocódigo.
  • Pull: es la acción de descargar y actualizar en tu repositorio local los cambios que existen en el repositorio remoto.
  • Push: es la acción de subir los cambios realizados en tu repositorio local al repositorio remoto.
  • Repositorio: es un lugar donde se almacenan y organizan archivos de un proyecto, especialmente código fuente. Permite guardar cambios, colaborar con otras personas y llevar un historial de versiones.
  • Scratch: es un programa para aprender programación usando bloques.
  • Script: es un conjunto de pasos que se ejecutan automáticamente.
  • Trabajo colaborativo: es cuando varias personas trabajan juntas en un mismo trabajo.
  • Variable: es un espacio de memoria en donde se almacena un dato que puede variar.
